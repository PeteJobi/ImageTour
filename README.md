Using ImageTour, you can create a video that "tours" around a large-resolution image, especially for cases where said image is too huge to share. You control the movement by setting multiple keyframes in the image, and the intermediate frames are extrapolated. You also control the duration of each transition, and the frames per second (fps) of the output video.
Only supports Windows 10 and 11 (not tested on other versions of Windows).
